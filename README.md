# Student Marks Calculator

A beginner-friendly web project that calculates a student's total marks, percentage, grade, and pass/fail status for five subjects.

## Features
- Optional student name
- Marks input for five subjects (0–100)
- Total out of 500 and percentage
- Grade calculation
- Pass/fail status (35 marks minimum in every subject)
- Input validation and responsive design

## Technologies
- HTML
- CSS
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Enter marks and click **Calculate Result**.

## Publish with GitHub Pages
1. Create a public repository named `student-marks-calculator`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment settings, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website.

## Grade rules
- A+: 90–100%
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: below 50% if every subject is passed
- F: fail if any subject is below 35 marks

*This is a learning project. Grade rules can be changed to match your institution's requirements.*
